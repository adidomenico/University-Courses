# Computer Networks
Third year of Bachelor's Degree in Computer Engineering at University of Bologna (2020/2021)

The course combines lectures and laboratory sessions in an integrated way, with lab projects on the tools covered in class to be carried out individually and in groups.

- Distributed Systems: General Concepts
    - General overview and basic definitions of distributed systems
    - Decentralized and heterogeneous distributed systems
    - The need for standardization of solutions (ISO/OSI and Internet)
    - Characteristic models
        - Client/server interaction model
        - Shared-memory and message-passing models
        - Connection, replication, and other models
- Standard Environments
    - Standardization
    - ISO/OSI layered organization
        - Transport and network layer
        - Application layers: session, presentation, and application
    - Some standard distributed applications
- TCP/IP Protocols
    - Protocols of the TCP/IP suite: network and transport layers
    - Common applications
        - Synchronous services: remote virtual terminal, file transfer
        - Asynchronous services: mail, news, and others
    - Widely used UNIX and Windows tools at the various layers
- Reference Tools
    - Communication sockets and related primitives
        - Sockets in C (for UNIX) and in Java
    - Examples of interaction in UNIX systems and connections with TCP/IP
    - Client/server applications
        - Remote Procedure Calls (RPC)
        - RMI: remote operations in Java
- Distributed Operating Systems and Services
    - Distributed operating systems
    - Resource naming
    - Process granularity and interaction
    - Resource management
    - File systems
    - Problems and possible solutions
    - Naming systems and DNS
    - Solutions to avoid congestion and protocol evolution
