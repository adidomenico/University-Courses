# Image Analysis and Computer Vision
First year of Master's Degree in Computer Science and Engineering at Politecnico di Milano (2021/2022)
[EIT Digital Data Science double Master's Degree](https://masterschool.eitdigital.eu/data-science)

The course covers the foundations of image formation, image analysis, and 3D scene reconstruction: optical, geometric, and algorithmic aspects, plus signal processing and data analysis. A project allows to closely examine, possibly from a practical point of view, one or more of the discussed topics.

- Introduction
- Camera Sensors
    - Transduction, optics, geometry, distortion
- Basics of Projective Geometry
    - Modelling basic primitives (points, lines, planes, conic sections, quadric surfaces)
    - Projective spatial transformations and projections
- Camera Geometry and Single View Analysis
    - Calibration, image rectification, localization of 3D models
- Multi-View Analysis
    - 3D shape reconstruction, self-calibration, 3D scene understanding
- Linear Filters
    - Convolutions, space-invariant filters, Fourier Transform, sampling and aliasing
- Nonlinear Filters
    - Image morphology and morphology operators (dilate, erode, open, close), median filters
- Edge and Feature Detection
    - Feature matching and feature tracking along image sequences
- Parametric Model Inference
    - Inferring models from noisy data (including outliers), contour segmentation, clustering, Hough Transform, RANSAC
- Applications
    - Object tracking, object recognition, classification
